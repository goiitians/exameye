# Seat in a plain file; seed defaults whenever settings are missing (2026-09-23)

## Root cause
After the v0.1.5 install on a centre PC the setup page opened with every field blank and no seat.
The service worker seeds settings from `defaults.json` only in `installed()` when
`reason === 'install'`, and `seedDefaults()` swallows a fetch or parse failure silently
(`src/sw.js:552-560`). Reproduced negative: the same extension folder produced by
`Install-ExamEye.command` seeds correctly in headless Chromium (options page opens, seat set), so the
blank page on Windows is either (a) a `defaults.json` the batch rewrite left unparsable, or
(b) a load that was not a first install. The batch rewrite of JSON cannot be executed or tested on
any machine we have, so it is removed as a class: the installer writes the seat to a one-line text
file and never touches JSON, the worker seeds whenever it has no settings, and a failed seed is
recorded where the popup shows it.

## Task 1 — `src/sw.js` (`seedDefaults`, `installed`)
```
// A centre ships its settings as defaults.json next to manifest.json and the desk's seat as
// seat.txt beside it (both written by the installer, see tools/build-installer.mjs); they are
// used only when no settings exist yet and never replace saved ones. A failed seed is recorded
// in meta.lastError so the popup shows it.
async function seedDefaults() {
  const { config } = await store.get('config');
  if (config) return false;
  let raw;
  try {
    const r = await fetch(chrome.runtime.getURL('defaults.json'));
    if (!r.ok) throw new Error(`HTTP ${r.status}`);
    raw = await r.json();
  } catch (e) {
    await store.patchMeta({ lastError: `${new Date().toISOString()} defaults.json: ${e?.message || e}` });
    return false;
  }
  try {
    const r = await fetch(chrome.runtime.getURL('seat.txt'));
    if (r.ok) { const seat = (await r.text()).trim(); if (seat) raw = { ...raw, seat }; }
  } catch {}
  await store.set({ config: normalize(raw) });
  return true;
}

async function installed(d) {
  const reason = d?.reason;
  const seeded = await seedDefaults();
  await boot();
  await enqueue(writeStateNow);
  if (reason === 'install' || seeded) await chrome.runtime.openOptionsPage();
}
```
