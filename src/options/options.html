ExamEye setup

Fill in the five sections once per machine, then click Save. Recording starts and stops on its own when a paper opens.

A paper is being recorded on this machine right now. Anything you save here is written into that paper's log, with the names of the fields you changed. The folder for the paper in progress does not change.

1Exam website

Which web addresses belong to the exam. ExamEye starts when the start page opens and treats everything on the same site as part of the paper.

The address every candidate lands on first, up to but not including the part that differs per candidate.

Only needed when the questions are served from a different address than the start page.

The address shown once the paper is submitted. Can be left blank when a submit button or a submitted-screen phrase is set in section 2.

2How the paper starts and ends

ExamEye needs one way to notice the end of the paper: a submit button, a phrase on the "submitted" screen, or the result page above.

The exact text on the button that starts the paper, for platforms where the page address does not change. Leave blank to start recording as soon as the start page opens.

The text on the button that finishes the paper. If the platform asks "Are you sure?", use the text of that confirm button. Separate several with commas.

A sentence that appears only on the "your answers have been submitted" screen and nowhere else in the paper.

A backstop: the recording ends this long after it started even if no submit was seen. 0 turns it off. Use the scheduled length plus a small margin.

How long to keep recording after the paper is submitted, to catch what happens next. 0 stops immediately.

3This machine

How the recordings from this desk are named and where they are kept.

Goes into every folder name so a recording can be matched to this desk.

All recordings go into this folder inside Chrome's download location, one sub-folder per paper.

4Recording

Screenshots are taken whenever something happens (a tab switch, a copy, a window change) and at a routine interval.

A picture of the exam tab at this interval, on top of the ones taken when something happens.

If the exam tab is closed and does not come back within this time, the paper is closed as abandoned.

5Screen capture

Besides the exam tab, ExamEye can photograph the whole screen while the candidate is away from Chrome. The candidate is asked once per paper to share their screen.

Frames are taken only while Chrome is not the active window and at each routine screenshot. Set to Off only where the centre forbids screen recording.

If the candidate cancels the share dialog, ask again after this long. 0 asks only once.

Chrome's "Ask where to save each file before downloading" (chrome://settings/downloads) must be off, or every screenshot and log will prompt for a save location.
