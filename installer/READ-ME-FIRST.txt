ExamEye installer
=================

What is in this folder
  ExamEye\                  the extension (do not open or edit; the installer copies it)
  Install-ExamEye.cmd       Windows: double-click this
  Install-ExamEye.command   macOS: double-click this (or run it from Terminal, see below)
  Update-ExamEye.ps1        Windows updater (the installer registers it; nothing to run by hand)
  update-exameye.sh         macOS updater (same)
  ExamEye-guide.pdf         what ExamEye does and how to read its reports
  ExamEye-overview.pptx     the same as slides

Get this folder from GitHub instead of a pen drive
  Open https://github.com/goiitians/exameye/releases, download exameye-installer.zip from the
  newest release, extract it, then follow the install steps below from the extracted folder.

Automatic updates
  The installer registers a job that runs at logon and once an hour. It downloads a newer release
  when there is one and replaces the ExamEye folder only while Chrome is closed, so a running exam
  is never touched. The new version is live the next time Chrome starts. The ExamEye popup shows
  the running version. Log: <home>\ExamEye-updater\update.log (one line per run).
  The updater owns <home>\ExamEye.new and <home>\ExamEye.old and deletes them; do not keep a backup under those names.

Publish a new version (owner)
  Once only, before the first release: GitHub > Settings > General > Danger zone > Change
  visibility > Public. Machines download releases without a login; on a private repo every PC
  logs "failed: cannot read version.txt" forever. Then, on one Windows PC with Chrome closed,
  run the updater by hand (below) and confirm "updated" in update.log and the version in the popup.
  GitHub > Actions > Release > Run workflow (branch main). Wait for the green tick; the release
  v0.1.<number> appears under Releases. Machines pick it up within an hour of their next Chrome
  restart. Do not publish during exam hours. To check the updater on one PC right away:
  close Chrome, then run  powershell -NoProfile -ExecutionPolicy Bypass -File %USERPROFILE%\ExamEye-updater\Update-ExamEye.ps1
  and read the last line of update.log.

Install on a Windows machine
  1. Double-click Install-ExamEye.cmd. It copies ExamEye to C:\Users\<you>\ExamEye,
     asks for this desk's seat ID (press Enter to keep C01) and opens Chrome's Extensions page.
  2. In Chrome: switch "Developer mode" on (top right), click "Load unpacked",
     paste the folder path (the installer put it on the clipboard), click "Select Folder".
  3. The ExamEye setup page opens by itself with all fields filled in.
     Check the seat ID and click "Save settings".
  4. Still on the Extensions page: ExamEye > Details > "Allow in Incognito": on.
  5. Chrome Settings > Downloads: "Ask where to save each file before downloading": off.

Install on a Mac
  Same steps with Install-ExamEye.command; the extension is copied to /Users/<you>/ExamEye.
  If double-clicking says the file cannot be executed, open Terminal and run:
     bash "/Volumes/<pen drive name>/exameye-installer/Install-ExamEye.command"
  In the "Load unpacked" dialog press Command-Shift-G to paste the path.
  Also: System Settings > Privacy & Security > Screen Recording > enable Chrome, then quit and reopen Chrome.

Then, on every machine (10 minutes)
  Open the exam start page in a new tab. The ExamEye icon shows a red 0 and its popup says ARMED.
  Switch to another tab and back, minimise and restore the window, then open the result page
  or submit the test paper. Look in Downloads\ExamEye for the new session folder.
  The full checklist is in the guide, section 4, step 5.

Which settings are pre-filled
  Exam start page       https://testplatform.aakash.ac.in/index.html
  Paper pages           (blank: every page of the site counts as the paper)
  Result page           https://testplatform.aakash.ac.in/results/final/index.html
  Start button          (blank: recording starts when the start page loads)
  Submit button         Submit
  Submitted phrase      Subject Analysis
  Maximum length        190 minutes;  keep watching after submit 5 minutes
  Seat or centre ID     C01 (the installer asks; change it per desk)
  Folder                Downloads\ExamEye
  Routine screenshot    every 5 minutes;  give up after the tab is gone 15 minutes
  Screen capture        on;  ask again after a refusal 1 minute
  To change them for a whole batch of machines, edit ExamEye\defaults.json on the pen drive
  before installing. They can also be changed any time on the setup page.

Do not move or delete the ExamEye folder after installing: Chrome switches the extension off if it disappears.
